# attenlo-local-processing

Resolve document paths relative to the handoff directory or the explicitly mapped new-repository equivalent.

Read docs/03_ENGINE_STRATEGY.md and docs/05_PRIVACY_AND_SECURITY.md. Validate local input handles and capabilities; preserve originals. Use typed deterministic operations, no model-authored code. Implement real processing and independent validation. Verify OCR text layers, truthful compression and no document-content egress. Record engine/version/licence and actual test results. Do not send files to cloud as a fallback.
