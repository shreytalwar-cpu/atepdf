# atepdf final v7 fresh-build implementation rules

## Selected foundation and authority
Read `DECISIONS_AND_PRECEDENCE.md`, `STACK_DECISION.md` and `START_HERE.md` first. Web uses shadcn/ui + Vercel AI SDK with selective minimal chatbot-template reuse. assistant-ui is the fallback only; do not install both. Build new SwiftUI Apple targets and a new Kotlin/Compose Android target; old native source is read-only learning input. No additional design selection is needed.

A nested handoff file does not automatically govern sibling app code. Create or carefully extend the NEW root instructions using `implementation/REPOSITORY_RULES_SNIPPET.md`. Never edit the old repo instructions. Keep existing safety constraints. Do not edit global agent configuration.

Read only the documents required for the current slice before implementing. Maintain actual app evidence and continue dependency-ready tasks. The original technical/growth backlogs remain; the integration overlay is not duplicated feature work.


## Product and precedence
This pack supersedes older feature-rich toolkit briefs for this product. Latest scope: web, Android, iOS/iPadOS and Mac; cloud instruction interpretation; strictly local document processing; approved pastel drop-and-instruct interface. Existing repository safety instructions still apply. Read `DESIGN.md` before UI changes and the operation contract before engine changes.

## Always
- Work only in the NEW atepdf repository; preserve any new-project progress and uncommitted changes. Old Attenlo PDF remains read-only.
- Fresh implementation is explicitly authorised. Reuse upstream engines and evidence-backed isolated helpers, not the old application skeleton. Read fresh-start/LEGACY_LEARNING_PROTOCOL.md.
- Native Apple app remains native. Android has native file/share integration. Web processes through local workers, not server actions.
- The UI is the product: low decision count, excellent defaults, visible buttons, no tool hunting.
- File contents, previews, OCR text, passwords and paths never enter the planner, telemetry or error-reporting pipeline.
- Cloud request serialization uses a positive allowlist and anonymous file/version references.
- Backend owns provider credentials; never embed them in distributed apps.
- AI can propose only allowlisted, versioned operations. Validate schema, file refs, page semantics, limits, capability and graph ordering on both trust boundaries.
- User-selected originals are immutable. New outputs are versioned. Undo selects a prior version rather than rewriting history.
- Progress and success derive from local engine events and measured output, never prose hallucinated by the model.
- Validate outputs with an independent reader where available; do not equate successful save with correctness.
- Ask only necessary clarifications. Do not ask permission for every safe copy operation.
- Preserve document features or report unsupported features; never silently destroy text, tags, links, annotations, form appearances or signatures.
- Use secure local controls for passwords. Reject signing/editing/redaction requests gracefully.
- Lazy-load heavy engines and language assets. Keep the UI responsive and make cancellation reliable.
- Record exact dependency versions, upstream source, licence and transitive obligations. Gate new copyleft/commercial dependencies for review.
- A missing capability produces a truthful local explanation, not an automatic cloud fallback.
- Build, run, visually inspect and test. Keep release evidence separate from aspirations.

## Never
- Add permanent sidebar navigation, a tool grid, model picker, upload dashboard or workflow diagram to the primary workspace.
- Add excluded editing/annotation/signing/form/redaction/watermark features.
- Upload documents to make a feature work; invoke cloud OCR/conversion/compression; send document contents to a model.
- Treat `pdf-lib` as a decryption engine or `ignoreEncryption` as unlocking.
- Treat OCR text recognition as a complete searchable-PDF implementation.
- Treat qpdf stream optimisation as guaranteed target-size compression.
- Generate and run arbitrary model-authored JavaScript, shell commands or filesystem paths.
- Claim fully offline AI, zero retention, universal language support or perfect conversion.
- Overwrite existing product instructions, unrelated branches or user work when installing this handoff.
- Publish, purchase, send customer emails, create paid services or change production billing without explicit authority.
