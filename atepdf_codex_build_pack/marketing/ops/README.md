## Stop expanding the tool list
Research: Appllama and Exa. Production: existing browser tooling and Remotion. Implementation: the NEW atepdf web/native repository; old Attenlo PDF is a read-only reference. Measurement: PostHog and verified billing records. Acquisition: Meta first, via verified Windsor access where suitable. Organic publishing: Buffer. Email: Resend. Subscription integration: RevenueCat when used by the actual app.

Use existing access first. Third-party account status is **unverified in Codex** until a permitted read succeeds. No production connections, schedules, purchases or sends are created by unpacking this folder.

## First deliverables
A working product slice remains first. Then produce one real demo, one matched page, one verified purchase-event path, three creative drafts and a read-only scorecard. Connect only the next tool required for those outputs.

The new OP tasks extend existing PM01–PM24; use their mappings rather than creating duplicate implementation. No large CRM, affiliate platform, standalone BI warehouse or autonomous ad-spend agent is required.
