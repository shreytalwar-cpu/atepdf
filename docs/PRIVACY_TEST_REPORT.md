# Local processing and privacy evidence
2026-09-28; development slice only.

The browser fixture tests record requests while importing, merging, previewing, saving, removing a page, undoing, adding actual English OCR text and compressing. They assert every workflow request is a same-origin GET and that no planner/API request occurs. They also check for browser runtime errors. Logs are docs/evidence/network-merge.json and network-chain.json. Static fixtures and engines load from localhost. Document filenames, PDF bytes, rendered pixels, OCR text, paths, passwords and local checksums are never serialized into any network request by these flows. Synthetic fixtures include canary strings; no POST/upload or external destination exists in the observed workflows.

Core tests inspect the allowlisted planner request projection and reject added metadata fields, stale revisions, wrong request bindings, duplicated/future references and partial/incomplete plans. All complete envelopes validate before engine dispatch. Ajv validators are generated ahead of time. Production CSP blocks external connections, frames and objects; it permits local WASM and local worker resources. Browser previews render local bytes, without external document URLs. No runtime analytics client is configured.

The local-only planner gateway now uses Vercel AI SDK with the OpenAI Responses API. The owner saved a key through a masked local field and approved at most two synthetic planning calls. Both succeeded, with no retries; merge and page removal ran in local engines only after complete schema/semantic validation and confirmation. The browser DTO evidence is `evidence/planner/live-test.json`. Known filenames are replaced by opaque refs; secret/path/encoded-data/known-document-snippet guards and a second positive projection run before provider transport. The SDK adapter test verifies `store:false`, strict structured output, a 2,000-output-token cap, no tools/file endpoints and disabled telemetry. This is source/adapter evidence, not a TLS packet capture or provider retention audit.

After both calls, local status confirmed the key present, zero remaining requests and paid planning disabled (`evidence/planner/live-budget-final.json`). The endpoint refuses further planning before provider invocation. A shared persistent reservation/lock covers both loopback hosts; failure/cancellation consumes a reserved allowance. Normal regression/browser tests use dummy keys and mocked provider responses, not the owner key. The separate live runner is excluded from normal tests. The key stays in an ignored 0600 local file within a 0700 directory; no key material is recorded in evidence. It is not OS-keychain storage or production authentication.

Independent PDF.js validation runs after pdf-lib transforms. Local originals are copied into private storage and remain immutable. Jobs stage intermediate outputs and commit only after all steps validate. Save receipts distinguish picker cancellation, actual writable-stream close, and browser download start. Tests verify undo restores identical bytes, cancellation commits no new PDF, and another job can run after OCR initialization is cancelled. Session clearing asks inside chat; a before-unload guard also covers imported originals.

Limits: automated Chrome desktop/responsive tests are not device network capture or production penetration testing. No physical-device privacy test, crash telemetry audit, encrypted PDF processing, or production retention proof is claimed. Native engines remain disabled. Billing sandbox tests were not run because billing has not been implemented or configured. Exactly two owner-approved paid planner calls were made; actual invoiced cost was not retrieved. No publication or migration took place.

The arbitrary 20 MB per-file, 40 MB aggregate/output and 100 MB retained-history gates were removed. Real 21,235,242-byte PDFs merged to 42,469,826 bytes, then previewed/saved/removed/undone without document egress (`evidence/planner/large-files.json`). Page/decoded-image/feature support and device memory remain practical limits.
