# Local processing and privacy evidence
2026-09-28; development slice only.

The browser fixture tests record requests while importing, merging, previewing, saving, removing a page, undoing, adding actual English OCR text and compressing. They assert every workflow request is a same-origin GET and that no planner/API request occurs. They also check for browser runtime errors. Logs are docs/evidence/network-merge.json and network-chain.json. Static fixtures and engines load from localhost. Document filenames, PDF bytes, rendered pixels, OCR text, paths, passwords and local checksums are never serialized into any network request by these flows. Synthetic fixtures include canary strings; no POST/upload or external destination exists in the observed workflows.

Core tests inspect the allowlisted planner request projection and reject added metadata fields, stale revisions, wrong request bindings, duplicated/future references and partial/incomplete plans. All complete envelopes validate before engine dispatch. Ajv validators are generated ahead of time. Production CSP blocks external connections, frames and objects; it permits local WASM and local worker resources. Browser previews render local bytes, without external document URLs. No runtime analytics client is configured.

The planner endpoint returns 503 before reading a body. Vercel AI SDK is installed but no provider or credential is configured. Conversation input never triggers provider calls. This build deliberately does not simulate hosted AI. Future hosted consent, instruction redaction (including document details typed by the user), transport and budget tests must pass before enabling the gateway. Current serialization tests alone do not prove future hosted privacy.

Independent PDF.js validation runs after pdf-lib transforms. Local originals are copied into private storage and remain immutable. Jobs stage intermediate outputs and commit only after all steps validate. Save receipts distinguish picker cancellation, actual writable-stream close, and browser download start. Tests verify undo restores identical bytes, cancellation commits no new PDF, and another job can run after OCR initialization is cancelled. Session clearing asks inside chat; a before-unload guard also covers imported originals.

Limits: automated Chrome desktop/responsive tests are not device network capture or production penetration testing. No physical-device privacy test, crash telemetry audit, hosted credential test, encrypted PDF processing, or production retention proof is claimed. Native engines remain disabled. Billing sandbox tests were not run because billing has not been implemented or configured. No payments, spend, publication or migration took place.
