## Integration failures found and corrected

The first iOS binary compiled but crashed on launch because Xcode/iOS 27 requires scene lifecycle adoption. The project now uses Expo 57's built-in scene delegate. A sustained simulator launch proved that fix separately from compilation. Native chat layout then exposed Uniwind's scoped-package resolver behavior: assistant-ui primitives received unprocessed classes. Native-only `withUniwind` wrappers adapt the official primitives; the web branch retains the originals.

Mac compilation initially rejected React Native pod deployment defaults that map to unsupported macOS 10.15 in the installed SDK. The app and its pod configurations now share the existing iOS 16.4 minimum and supported Catalyst settings. Actual Catalyst compilation/linking passes. Local signing encountered Finder metadata on generated products under the Documents filesystem and flattened duplicate upstream framework versions. The repeatable build script stages a fresh temporary copy, verifies duplicate contents, normalizes only the staged framework layout and strictly verifies nested ad-hoc signatures. The local ad-hoc signature omits Hardened Runtime because its libraries have no real Team ID; production target settings remain unchanged. This is not a distributable release.

An early bundle-ID lookup launched an unsigned generated Mac copy. No PDFs were imported, but no pre-launch cache baseline existed, so historical startup cleanup cannot be proved harmless. A bounded metadata audit found the relevant global directories absent afterward. This prompted the native storage-isolation gate and removal of generic picker-directory sweeping. Final testing launches only the exact staged, verified app path. See `evidence/native/mac-unsigned-launch-audit.json`.

Independent PDFKit text checks caught concatenated OCR words. Explicit invisible word separators now make the output searchable in both independent readers. A web cancellation test originally depended on whether the developer had a saved key; it now sets its intended no-key status through a mock and does not touch private configuration.

Final Mac visual inspection caught a native raster defect that page counts and searchable text had not exposed: CoreGraphics' drawing transform scales down, but does not scale up. Larger bitmaps therefore contained undersized centered content, and Vision coordinates inherited that padding. Explicit bitmap scaling before the logical-point crop/rotation transform fixes preview geometry and OCR placement. Pixel-anchor checks, absolute OCR-position checks, the actual shared processing chain and an isolated old-transform failure establish the correction independently. Native Send also now looks disabled when its official runtime state is disabled; no submission semantics or dependency source changed.
