Copied thread/composer/message, icon, surfaces, typing indicator and icon-button source. The original MIT licence is retained in assistant-ui-LICENSE. Kept the upstream FlatList, keyboard offset, composer send/cancel and copy primitives; measured following refinements are recorded below. Adaptations: atepdf tokens/labels; local PDF/confirmation/key-entry host slots; single screen without thread-list navigation; hidden unsupported edit/reload controls; scrollable welcome on compact screens. Removed generalized remote attachment/image/file/markdown/tool rendering paths from this recipe because atepdf accepts structured local plans, not document-aware model messages. Existing clsx/tailwind-merge implement the small cn utility instead of adding another cn package.

The registry snapshot lists dependencies reviewed, including components not copied into atepdf. No default image attachment picker, base64-to-model path, tool fallback or cloud thread persistence was installed/configured. Transitive assistant-cloud is present through the upstream runtime package but unused; browser network tests verify no cloud/analytics requests in tested flows.

This review is provenance/licence/version/compatibility evidence. It is not production distribution approval or a complete vulnerability audit.

Native input integration: `apps/universal/src/platform/ComposerInput.native.tsx` uses the documented ComposerInput extension slot for the new-message composer. UIKit owns text/caret through a stable defaultValue (no controlled value); changes mirror to public composer.setText, and public composer.send clears the input. Thread, messages, Send/runtime and web input remain upstream. Real iPhone XCTest caught fast-input corruption; disabling autocorrection and a narrow public flushTapSync package patch both failed and were reverted. The original pinned package and dependency metadata are retained. Exact investigation and regression evidence: `../evidence/native/native-composer-investigation.json` and `../../tests/native/ios/README.md`. Edit/retry/voice prefills are not enabled; future programmatic draft features need explicit handling/tests.


Chat refinement: added a small local Activity host slot in the copied Thread recipe; the public runtime and Composer Send/Cancel remain unchanged. The activity uses upstream motion/announcement helpers and real controller step facts. Native uncontrolled input behavior is preserved while its size/placeholder contrast are refined. The existing FlatList reference/metrics provide an accessible Latest message button; public scrollToBottomOnRunStart=false avoids animated short-job races while keeping upstream content and keyboard following. Final assistant text has a polite web live region, with native finalized responses announced through the existing helper. No dependency patch is retained.

The native Send appearance reads the public composer.canSend state because the wrapped native primitive does not receive the web disabled pseudo-class styling. This sets opacity only; official Send still owns submission and disabled behavior.


29 September UX refinement: explicit submissions and Latest message use the existing FlatList's measured content/viewport bounds. Deliberate upward reading suspends following, and public automatic-scroll props are disabled to avoid competing handlers during short local jobs. Artifact messages omit the text Copy row because Save/Preview belong to the local PDF result. The native preview extends the existing viewport context with a measured-region reveal on keyboard/viewport changes; it does not control the draft, move keyboard focus or change the runtime. Web has no native reveal side effect. Browser follow/read regressions and native simultaneous keyboard/preview regressions exercise these adaptations.

Icon imports use the pinned Lucide native package's supported `./icons/*` exports, including the identical FilePlus2 vector through its file-plus-corner alias on web. This changes startup dependency reachability rather than icon design or dependency versions. See `../evidence/ux/2026-09-29/performance/README.md`. Check future exports with `node scripts/check-web-budget.mjs <export-directory>` from repository root; the initial-script budget is 2.5 MB raw / 500 KB computed gzip. Lazy local PDF engines retain separate functional/resource tests.
